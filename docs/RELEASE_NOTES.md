Download the archive matching your computer below. Extract the complete archive.

- Windows x86-64: run `editor.exe` inside the extracted folder.
- macOS Apple Silicon: choose `macos-aarch64`; move `editor.app` to Applications.
- macOS Intel: choose `macos-x86_64`; move `editor.app` to Applications.
- Linux x86-64: extract the `.tar.gz` and run `./editor` (Ubuntu 22.04 or compatible newer system).

Windows builds are unsigned; macOS builds are ad-hoc signed without notarization.
First launch may require approval in your operating system's security settings.
See the included `INSTALL.md` for instructions and optional feature requirements.
All packages include themes and license notices. SHA-256 hashes are in `SHA256SUMS.txt`.
